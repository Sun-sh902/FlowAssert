# Security policy

## Supported versions

Only the latest release and the `main` branch receive fixes.

## Reporting a vulnerability

Please do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/Sun-sh902/FlowAssert/security/advisories/new) and include steps to reproduce with synthetic data.

This project has one maintainer, so a reply may take some days. There is no bug bounty.

## Scope

The Service and UI are built for one local user and synthetic data. They have no authentication and must not be exposed to a network. The README's security model explains what each control does and does not protect.

Treat this code as unaudited.
