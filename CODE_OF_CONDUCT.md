# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion on the work. Harassment and personal attacks are not accepted.

To report a problem privately, use [GitHub's report form](https://github.com/contact/report-abuse) or open a [private security advisory](https://github.com/Sun-sh902/FlowAssert/security/advisories/new) on this repository. The maintainer may remove content or block accounts that break these rules.
